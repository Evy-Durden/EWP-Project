\subsection{Current Situation}

Misconfiguration on Linux machines can lead to a host of vulnerabilites related to privilege escalation. Through a comprehensive analysis these misconfigurations can be detected and the risks of compromise mitigated.\newline\newline Detecting misconfiguration statically (e.g. configs, permissions) is a very good start and a mandatory component of the analysis. However what is lacking is a behavioral approach. In addition to the analysing the machines statically this tool uses eBPF to oberserve runtime behavior. This feature adds a runtime security analyzer to the misconfiguration scanner.

\subsection{Objectives}

The tool achieves the following objectives:

\begin{itemize}
	\item static analysis to find misconfigurations
	\item behaviorial analysis to find runtime behavioral indicators
\end{itemize}

\subsubsection{Categories}

Misconfigurations and indicators can be found in the following categories:

\begin{itemize}
	\item Filesystem and Permissions
	\item User and Group
	\item Service and Daemon
	\item Network
	\item Package and Software Management
	\item Kernel and System Hardening
	\item Authentication and Authorization
	\item Logging, Auditing and Monitoring
	\item Timers, Cron
	\item Environment and PATH
	\item Container and Virtualization
	\item Security Feature
\end{itemize}

\subsection{Functional and non-function Requirements}

\subsubsection{Functional Requirements Static Analysis}

The static analysis inspects configurations and system state without observing runtime behaviour. The tool is able to enumerate relevant system properties like users, groups, privileges, file ownership, permissions and service as well as daemon configurations to just name a few. There will be extra focus on misconfigurations which could lead to privilege escalation. \newline\newline At its core the tool is a rule-based analysis engine which uses explicit rules to collect data and categorizes the findings. It is a deterministic approach which puts the ability to understand the findings in the foreground rather than heuristic detection.\newline\newline Furthermore each detected issue is provided with a severity level and contextual metadata such as the affected user or file.\newline\newline A full list of all functional requirements is provided in the appendix ~\ref{sec:a_frs}.

\subsection{Stakeholder Analysis}

The primary audience for this tool are system administrators for Linux machines. It is designed to aid them in finding misconfigurations and giving them a chance to subsequently harden their systems. \newline\newline This tool is open source. As a consequence anybody wanting to learn more about system configurations and associated vulnerabilities can benefit from this. It will give them insight on what configurations play a role in privilege escalation as well as how the code of this solution is built and how it works.

\subsection{Constraints and Limitations}

It does not change any configurations on a system.
